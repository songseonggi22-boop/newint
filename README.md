# 인트라넷 도우미 크롬 확장

## 설치 방법
1. 크롬 주소창에 `chrome://extensions/` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램 로드** 클릭
4. 이 폴더(`intranet-extension/`) 선택

> 아이콘 파일이 없으면 설치 시 경고가 뜰 수 있는데 무시하고 진행 가능. 
> 아이콘 추가하려면 icons/ 폴더에 icon16.png, icon48.png, icon128.png 넣기.

## 기능

### ① 영업일 시간표 (Alt+B)
- 오른쪽 하단 📅 영업일 보기 버튼 클릭
- 해당 월 공휴일·휴강일 날짜 입력 (예: 3,9,10)
- **저장 및 적용** → 시간표 날짜 셀에 "1영업일", "2영업일" 뱃지 자동 표시

### ② 컨택 검색 (Alt+S)
- 오른쪽 고정 패널 열기
- 날짜 + 담당자명 입력 → **검색 적용**
- 현재 페이지 필터 자동 채움 후 조회 버튼 자동 클릭

### ③ UI 개선 (자동)
- 테이블 zebra 배경, 행 간격, 폰트 14px
- 배정완료/미배정/상담예정 상태 색상 뱃지 자동 변환

## 주의
- 인트라넷 SPA 업데이트 시 필드명이 바뀌면 자동 채움이 안 될 수 있음
- 그 경우 content.js의 키워드 배열 수정 필요
