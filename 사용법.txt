==============================================
  인트라넷 도우미 (크롬 확장 프로그램) 사용법
  대상: 뉴인트라넷 kegone.koreagroupware.com
==============================================


[1] 설치 방법 (처음 한 번만)
----------------------------------------------
1. 받은 "intranet-extension" 폴더를 내 PC의 아무 곳에 둡니다.
   (예: 바탕화면) ※ 설치 후 폴더를 지우거나 옮기면 안 됩니다.
2. 크롬 주소창에 chrome://extensions 입력 후 엔터
3. 오른쪽 위 "개발자 모드" 스위치를 켭니다.
4. 왼쪽 위 "압축해제된 확장 프로그램을 로드합니다" 클릭
5. "intranet-extension" 폴더를 선택합니다.
6. 인트라넷 페이지를 새로고침(F5)하면 오른쪽 아래에 🏢 버튼이 생깁니다.


[2] 처음 설정 - 내 이름 등록
----------------------------------------------
1. 🏢 버튼 클릭 → 위쪽 "⚙️ 설정" 탭
2. "내 이름"에 인트라넷에 표시되는 내 이름 입력 → 저장
3. 이후 모든 표에서 내 이름이 들어간 행이 굵은 글씨로 표시됩니다.
   (수강생보기에서 내 담당 수강생 찾을 때 편리)


[3] 컨택 조회 - 오늘 연락할 DB 찾기
----------------------------------------------
결과메모에 적어둔 날짜(예: 10.12)로 그날 컨택할 DB를 한 번에 찾습니다.

1. 사업관리 → 문의DB → 멘토별문의DB 화면을 엽니다.
2. 🏢 버튼 → "📞 컨택조회" 탭
3. 날짜 선택 ("오늘" 버튼 누르면 오늘 날짜)
4. 담당자 이름 입력 (비우면 전체 담당자)
5. "🔍 조회" 클릭

자동으로 이렇게 진행됩니다 (약 4~5초, 화면 건드리지 말고 기다리기):
  - 검색 구분: 문의자 → 결과메모
  - 담당 구분: 메인담당 → 메인+서브
  - 검색어 칸에 날짜 입력 (10.12 형식)
  - 멘토선택 칸에 담당자 이름 입력
  - 조회 버튼 클릭 (정확도를 위해 자동으로 한 번 더 클릭)
패널에 "✅ 조회 완료"가 뜨면 끝입니다.

※ 결과메모에 날짜를 적을 때는 "10.12"처럼 월.일 형식으로 적어야 검색됩니다.
※ 다른 화면에서 조회를 누르면 멘토별문의DB로 이동을 시도합니다.
   이동이 안 되면 직접 멘토별문의DB를 연 뒤 다시 조회를 누르세요.


[4] 시간표 - 개강일로 기간 한 번에 설정
----------------------------------------------
1. 운영관리 → 시간표관리 → 시간표관리 화면을 엽니다.
2. 🏢 버튼 → "📅 시간표" 탭
3. 원하는 개강일 버튼 클릭 (예: 10.19)
4. 기간이 "그 개강일 ~ 다음 개강일 전날"로 자동 설정되고 조회까지 됩니다.

영업일만 체크 (체크박스가 있는 화면에서):
  - 연월 선택 → 공휴일·휴강일 날짜를 쉼표로 입력 (예: 3,9,10)
  - "✅ 영업일만 체크" 클릭 → 주말·공휴일 빼고 체크됩니다.
  - "전체" / "해제" 버튼으로 전체 체크·해제

내 수강생 보기 (시간표관리 화면에서):
  1. 개강일 버튼 등으로 원하는 기간의 시간표를 띄웁니다.
  2. 🏢 → "📅 시간표" 탭 맨 아래 담당자 칸에 이름 확인 (설정의 내 이름이 자동 입력)
  3. "👥 내 수강생 보기" 클릭 → 수업마다 수강생 창을 자동으로 열어 확인합니다.
     (수업 1개당 2~3초, 진행 중 화면 건드리지 말기 / 다시 누르면 중지)
  4. 확인이 끝난 수업부터 시간표 칸 맨 위에 노란 표시로 "👤 내 학생 이름"이 붙습니다.
     (내 학생이 없는 수업은 표시 없음 / 새로고침해도 표시 유지)
  5. 다음부터는 "👥 내 수강생 보기"를 누르면 새 수업·배정인원이 바뀐 수업만 확인합니다.
     (보통 몇 초면 끝남)
  ※ 한 번 확인된 학생 표시는 지워지지 않습니다 (새 학생은 추가만 됨)
     수강 취소·담당 변경으로 빼야 할 때나 멘토만 바뀐 경우 → "↻ 전체"로 다시 확인
  ※ 배정인원 0명인 수업은 건너뜁니다.


[5] 자동으로 바뀌는 화면 표시
----------------------------------------------
설치만 하면 표에 자동 적용됩니다.

  상태 표시 (작은 타원형 색 뱃지 · DB 목록 표에서만 표시, 상세화면은 그대로)
    배정완료 ........ 초록
    미배정 .......... 빨강
    상담예정/내사예약  파랑
    컨택/컨택완료 ... 노랑
    전화안받음 ...... 보라
    상담완료 ........ 민트
    재컨텍요망 ...... 연노랑

  완납 / COD ........ 굵은 글씨
  내 이름이 있는 행 .. 굵은 글씨 (설정에서 이름 등록 시)
  표 전체 .......... 글자 14px, 줄 간격·줄무늬로 가독성 개선


[5-1] 🔒 일괄 - 다음컨택일 한 번에 넘기기 (비밀번호 필요)
----------------------------------------------
1. 🏢 → "🔒 일괄" 탭 → 비밀번호 입력 → 열기 (그 PC에서는 한 번만)
2. 도메인별/멘토별문의DB 목록에서 넘길 DB 왼쪽 체크박스 체크
3. "📋 체크한 DB 불러오기" → 목록 확인, 뺄 DB는 체크 해제
4. 넘길 날짜 선택 (결과메모·상담내용은 자동으로 채워짐, 고쳐도 됨)
5. "🚚 넘기기" → 확인창에서 명단 한 번 더 확인 → 확인
   건마다 상담일지에 상담메모가 새로 저장됩니다 (상담결과는 지금 상태 그대로)
※ 상담메모는 저장 후 수정할 수 없습니다. 처음엔 1건만 체크해서 시험해 보세요.
※ 한 건이라도 실패하면 거기서 멈추고 이유를 보여줍니다.


[6] 단축키
----------------------------------------------
  Alt + K : 패널 열기 / 닫기
  🏢 버튼 위치 옮기기 : 버튼을 마우스로 꾹 눌러 원하는 곳으로 끌어다 놓기 (위치 기억됨)


[7] 안 될 때
----------------------------------------------
- 🏢 버튼이 안 보이면: 인트라넷 페이지 새로고침(F5)
- 업데이트 파일을 받았으면: 폴더 내용을 새 파일로 바꾼 뒤
  chrome://extensions 에서 "인트라넷 도우미"의 새로고침(↻) 버튼 클릭 → 인트라넷 F5
- 컨택 조회 결과가 이상하면: 조회 버튼을 한 번 더 눌러보세요.
- 그래도 안 되면 F12 → Console 탭에서 [KIH]로 시작하는 문구를 캡처해서 담당자에게 전달
